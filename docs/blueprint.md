# **App Name**: AlertLoc

## Core Features:

- Location-Based Reminders: Trigger reminders when the user arrives at a specified location.
- Map Integration: Display reminders on a map using pins with different colors to indicate their urgency or group association.
- Group Sharing: Share reminders with family and friends for collaborative task management.
- Geofencing: Enable real-time geofencing to accurately detect when a user enters a specified radius.
- Customizable Radius: Allow users to adjust the radius for triggering reminders, ranging from 50m to 1km.
- Recurrence Options: Provide options for recurring reminders or one-time alerts.

## Style Guidelines:

- Primary color: Vibrant purple (#6C63FF) for main UI elements, evoking a sense of innovation.
- Background color: Dark mode with a main background of #1A1A2E (dark gray), providing a modern look.
- Accent color: Electric cyan (#00D4FF) for interactive elements, drawing the user's attention.
- Headline font: 'Poppins', a sans-serif font, for titles, providing a modern, precise feel.
- Body font: 'Inter', a sans-serif font, for body text, offering a contemporary look.
- Location pin icon with an integrated bell in purple and cyan.
- Micro-animations for user interactions, such as a bouncing pin when creating a reminder, with smooth transitions set at 300ms.
